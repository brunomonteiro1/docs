<Steps>
  <Step title="Obtenha sua chave de API">
    Após a contratação será enviada a chave de API, caso não seja enviada contate o  Suporte ([atendimento@databox360.com.br](mailto:atendimento@databox360.com.br)).
  </Step>
  <Step title="Obtenha o token da API">
    Use a chave da API para obter o Token da API.

    {""}

    Consulte: [Autenticação](https://docs.databox360.com.br/api-reference/authentication).
  </Step>
  <Step title="Realize chamadas para API">
    Inclua o Token gerado no header `Authorization` para realizar as chamadas para nossa API.
  </Step>
  <Step title="Renove seu token">
    Os Tokens da API tem duração de 1 hora, após esse período você deve obter um novo token.
  </Step>
</Steps>
