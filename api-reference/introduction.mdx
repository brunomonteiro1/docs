A API DataBox360 foi desenvolvida de acordo com os melhores padrões REST.

As operações são realizadas por meio de requisições aos endpoints, utilizando os verbos HTTP apropriados e corpos de mensagem em JSON.

As respostas podem ser interpretadas por meio dos códigos de status HTTP, permitindo que qualquer aplicação consuma a API de forma simples, padronizada e independente da linguagem utilizada.

Para facilitar o processo de integração, disponibilizamos um ambiente Sandbox. Nele, você pode realizar os testes necessários sem cobrança pelas transações requisitadas.
