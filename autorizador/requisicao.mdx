---
title: "Início rápido"
description: "Autentique-se, registre uma autorização, consulte por documento e liste os registros em poucos passos."
---

Siga os passos abaixo para fazer a primeira integração com o Autorizador SCR. Todos os exemplos usam dados fictícios.

<Steps>
  <Step title="Autentique-se">
    Obtenha o token JWT a partir da sua API Key, conforme descrito em [Autenticação](/api-reference/autenticacao). Use o token no cabeçalho `Authorization: Bearer` das próximas chamadas.
  </Step>
  <Step title="Registre a autorização">
    Envie os dados do titular e da coleta do consentimento. Veja todos os campos em [Enviar autorização](/autorizador/enviar-autorizacao).

    ```bash
    curl -X POST https://api.databox360.com.br/api/autorizacoes \
      -H "Authorization: Bearer YOUR_JWT_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{
            "nome": "EMPRESA EXEMPLO LTDA",
            "documento": "11.222.333/0001-81",
            "tipoDocumento": "cnpj",
            "consentimento": true,
            "metadata": {
              "ip": "203.0.113.10",
              "host": "app.exemplo.com.br",
              "timestamp": "2026-01-15T10:00:00-03:00",
              "userAgent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/133.0.0.0 Safari/537.36"
            }
          }'
    ```
  </Step>
  <Step title="Consulte por documento">
    Confirme o registro informando o CPF ou CNPJ, apenas com dígitos. Veja [Consultar autorização](/autorizador/consultar-autorizacao).

    ```bash
    curl -X GET https://api.databox360.com.br/api/autorizacoes/autorizacao/11222333000181 \
      -H "Authorization: Bearer YOUR_JWT_TOKEN"
    ```
  </Step>
  <Step title="Liste os registros">
    Veja todas as autorizações registradas com a sua API Key. Veja [Listar autorizações](/autorizador/listar-autorizacoes).

    ```bash
    curl -X GET https://api.databox360.com.br/api/autorizacoes/ \
      -H "Authorization: Bearer YOUR_JWT_TOKEN"
    ```
  </Step>
</Steps>

<Tip>
  Para conhecer a plataforma antes de integrar, use o ambiente de testes em [autorizadorscr.com.br/app](https://www.autorizadorscr.com.br/app).
</Tip>
