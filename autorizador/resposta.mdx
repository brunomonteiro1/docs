As rotas utilizam códigos de status HTTP para indicar o resultado da requisição. Em caso de erro, o corpo da resposta traz uma mensagem descritiva.

## Autenticação

Se a API Key for inválida, a obtenção do token retorna `401`:

```json 401
{
    "messagem": "API Key Inválida",
    "status": "erro"
}
```

Para as demais rotas, envie sempre o token no cabeçalho `Authorization: Bearer YOUR_JWT_TOKEN`. Detalhes em [Autenticação](/api-reference/autenticacao).

## Boas práticas

- Valide o CPF/CNPJ e a correspondência com o `tipoDocumento` antes de enviar.
- Envie `consentimento: true` somente quando o titular tiver concedido o consentimento expresso.
- Garanta que `metadata.timestamp` esteja em ISO 8601 com fuso horário.
- Se receber `401`, obtenha um novo token e repita a requisição.
