</Info>

  /autorizacoes/

Retorna as autorizações registradas com a API Key utilizada na autenticação. A rota não recebe parâmetros.

<RequestExample>

```bash cURL
curl -X GET https://api.databox360.com.br/api/autorizacoes/ \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

```javascript JavaScript
const response = await fetch("https://api.databox360.com.br/api/autorizacoes/", {
  method: "GET",
  headers: {
    Authorization: "Bearer YOUR_JWT_TOKEN",
  },
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

url = "https://api.databox360.com.br/api/autorizacoes/"
headers = {"Authorization": "Bearer YOUR_JWT_TOKEN"}

response = requests.get(url, headers=headers)
data = response.json()
```

```php PHP
<?php
$url = 'https://api.databox360.com.br/api/autorizacoes/';

$options = [
    'http' => [
        'header' => "Authorization: Bearer YOUR_JWT_TOKEN",
        'method' => 'GET'
    ]
];

$context = stream_context_create($options);
$result = file_get_contents($url, false, $context);
$data = json_decode($result, true);
?>
```

</RequestExample>

## Resposta

<ResponseField name="sucesso" type="boolean" required>
  Indica se a requisição foi processada com sucesso. Valor esperado: `true`.
</ResponseField>

<ResponseField name="total" type="integer" required>
  Quantidade de autorizações retornadas em `data`.
</ResponseField>

<ResponseField name="data" type="array" required>
  Lista de autorizações registradas.

  <Expandable title="itens de data">
    <ResponseField name="data[].id" type="string" required>
      Identificador único da autorização no formato UUID.
    </ResponseField>

    <ResponseField name="data[].nome" type="string" required>
      Nome completo ou razão social do titular do consentimento.
    </ResponseField>

    <ResponseField name="data[].documento" type="string" required>
      Número do documento do titular sem formatação (apenas dígitos).
    </ResponseField>

    <ResponseField name="data[].tipoDocumento" type="string" required>
      Tipo do documento: `cpf` ou `cnpj`.
    </ResponseField>

    <ResponseField name="data[].consentimento" type="boolean" required>
      Confirma o consentimento registrado. Valor esperado: `true`.
    </ResponseField>

    <ResponseField name="data[].dataExpiracao" type="string" required>
      Data e hora de expiração da autorização, no formato `DD/MM/YYYY HH:mm:ss`.
    </ResponseField>

    <ResponseField name="data[].dataCriacao" type="string" required>
      Data e hora de criação da autorização, no formato `DD/MM/YYYY HH:mm:ss`.
    </ResponseField>

    <ResponseField name="data[].dataAtualizacao" type="string" required>
      Data e hora da última atualização da autorização, no formato `DD/MM/YYYY HH:mm:ss`.
    </ResponseField>

    <ResponseField name="data[].ip" type="string" required>
      Endereço IP registrado no momento da coleta.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  A listagem não inclui o `metadata` completo. Para ver os dados da coleta de um titular, use [Consultar autorização](/autorizador/consultar-autorizacao).
</Note>
