---
title: "Enviar autorização"
description: "Registra o consentimento do titular para consulta ao SCR Bacen, coletando dados de identificação e metadata da solicitação."
---

<Info>
  Esta rota requer autenticação via Bearer Token. Certifique-se de ter sua API Key e token JWT configurados conforme descrito em [Autenticação](/api-reference/autenticacao).
</Info>

<div class="relative flex-1 flex gap-2 min-w-0 rounded-xl items-center cursor-pointer p-1.5 border-standard">
  <div class="method-pill rounded-lg font-bold px-1.5 py-0.5 text-sm leading-5 bg-blue-400/20 dark:bg-blue-400/20 text-blue-700 dark:text-blue-400">
    POST
  </div>

  /autorizacoes
</div>

Se já existir uma autorização para o documento informado, o registro é atualizado e não duplicado. Veja [Conceitos](/autorizador/conceitos#reenvio-atualiza-o-registro).

## Requisição

<ParamField body="nome" type="string" required>
  Nome completo da pessoa física ou razão social da pessoa jurídica titular do consentimento.
</ParamField>

<ParamField body="documento" type="string" required>
  Número do documento do titular: `CPF` (pessoa física) ou `CNPJ` (pessoa jurídica). Pode ser enviado com ou sem pontuação; a resposta devolve apenas os dígitos.
</ParamField>

<ParamField body="tipoDocumento" type="string" required>
  Tipo do documento informado. Valores aceitos: `cpf` ou `cnpj`. Informe o tipo que corresponde ao número enviado.
</ParamField>

<ParamField body="consentimento" type="boolean" required>
  Indica se o titular concedeu o consentimento expresso para consulta ao SCR. Deve ser `true` para registrar a autorização.
</ParamField>

<ParamField body="metadata" type="object" required>
  Objeto com dados de contexto da coleta do consentimento, utilizados para rastreabilidade e auditoria.

  <Expandable title="metadata properties">
    <ParamField body="metadata.ip" type="string" required>
      Endereço IP (IPv4 ou IPv6) do dispositivo do titular no momento da coleta do consentimento.
    </ParamField>

    <ParamField body="metadata.host" type="string" required>
      Host da aplicação que realizou a coleta.
    </ParamField>

    <ParamField body="metadata.timestamp" type="string" required>
      Data e hora da coleta do consentimento no formato ISO 8601, com fuso horário. Ex: `2026-01-15T10:00:00-03:00`.
    </ParamField>

    <ParamField body="metadata.userAgent" type="string" required>
      User agent do navegador ou aplicação utilizada pelo titular no momento do consentimento.
    </ParamField>

    <ParamField body="metadata.location" type="object">
      Dados de geolocalização do dispositivo no momento da coleta (quando disponível).

      <Expandable title="location properties">
        <ParamField body="metadata.location.accuracy" type="number">
          Precisão da geolocalização em metros.
        </ParamField>

        <ParamField body="metadata.location.latitude" type="number">
          Latitude geográfica do dispositivo.
        </ParamField>

        <ParamField body="metadata.location.longitude" type="number">
          Longitude geográfica do dispositivo.
        </ParamField>
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

## Resposta

<ResponseField name="sucesso" type="boolean" required>
  Indica se a requisição foi processada com sucesso. Valor esperado: `true`.
</ResponseField>

<ResponseField name="message" type="string" required>
  Mensagem descritiva do resultado. Ex: `Consentimento registrado com sucesso`.
</ResponseField>

<ResponseField name="data" type="object" required>
  Objeto com os dados da autorização registrada.

  <Expandable title="data properties">
    <ResponseField name="data.id" type="string" required>
      Identificador único da autorização, gerado pela plataforma no formato UUID.
    </ResponseField>

    <ResponseField name="data.nome" type="string" required>
      Nome completo ou razão social do titular do consentimento.
    </ResponseField>

    <ResponseField name="data.documento" type="string" required>
      Número do documento do titular sem formatação (apenas dígitos).
    </ResponseField>

    <ResponseField name="data.tipoDocumento" type="string" required>
      Tipo do documento: `cpf` ou `cnpj`.
    </ResponseField>

    <ResponseField name="data.consentimento" type="boolean" required>
      Confirma o consentimento registrado. Valor esperado: `true`.
    </ResponseField>

    <ResponseField name="data.dataExpiracao" type="string" required>
      Data e hora de expiração da autorização, no formato `DD/MM/YYYY HH:mm:ss`.
    </ResponseField>

    <ResponseField name="data.dataCriacao" type="string" required>
      Data e hora de criação da autorização, no formato `DD/MM/YYYY HH:mm:ss`.
    </ResponseField>

    <ResponseField name="data.dataAtualizacao" type="string" required>
      Data e hora da última atualização da autorização, no formato `DD/MM/YYYY HH:mm:ss`.
    </ResponseField>

    <ResponseField name="data.ip" type="string" required>
      Endereço IP registrado no momento da coleta.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  Esta resposta não devolve o `metadata` completo. Para ver todos os dados da coleta, use [Consultar autorização](/autorizador/consultar-autorizacao).
</Note>
